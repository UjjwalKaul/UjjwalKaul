  - A zero-install, tactile web remote and TV keyboard served over local Wi-Fi by on-device QR code.
  - Featured on the official **[CleanYourTV Showcase](https://github.com/Gathin23/cleanyourtv/blob/main/SHOWCASE.md)**.
